# Privacy Policy for Easy Project Dashboard

    **Last Updated: September 2026**

    This Privacy Policy describes how **Easy Project Dashboard** ("the App") handles information when installed on Atlassian Confluence Cloud.

    ## 1. Data Storage & Hosting
    - **Easy Project Dashboard** is built entirely on the **Atlassian Forge** platform.
    - All dashboard configurations, custom titles, and uploaded datasets are stored securely within your **Atlassian Cloud Key-Value Storage (KVS)** and local browser storage.
    - **We do not host or operate any external servers.** No project data, file uploads, or metadata is ever transmitted to, stored on, or processed by external third-party servers.

    ## 2. Information Collected
    - The App does not collect, track, or sell any Personally Identifiable Information (PII).
    - User preferences (such as selected themes, density modes, and filters) are stored locally in the user's browser or within your Atlassian site instance.

    ## 3. Third-Party Access
    - No data is shared with or sold to third-party analytics, advertisers, or external services.

    ## 4. Security
    Because the App runs natively within Atlassian Cloud via Atlassian Forge, all data benefits from Atlassian’s enterprise-grade security, access controls, and encryption standards.

    ## 5. Contact
    If you have any questions regarding this Privacy Policy, please contact the developer via your Atlassian Marketplace support channel.
