Security Policy for Easy Dashboard

Last Updated: September 10, 2026

1. Introduction and Scope

This Security Policy outlines how we protect the data, infrastructure, and users of the Easy Dashboard app. We are committed to maintaining industry-standard security practices to ensure the confidentiality, integrity, and availability of our users' information within the Atlassian ecosystem.

2. Data Protection and Access

We implement strict measures to protect your data and adhere closely to Atlassian's security guidelines.

  • Data Storage: Easy Dashboard does not store End-User Data on any external servers. Project data can be saved directly in the user's own space within Atlassian, allowing it to be loaded from the dashboard for display.
  • Data Deletion: User data is deleted concurrently with the page it is associated with.
  • Data Residency: Because our app stores End-User Data exclusively within Atlassian apps and services, data residency is managed directly by Atlassian's infrastructure.
  • Access Control: We follow the principle of least privilege. The app requests only the minimum necessary scopes and permissions required for its functionality.
  • Authentication: We do not require, collect, or store Atlassian Personal Access Tokens (PATs), user account passwords, or other shared secrets.

3. Vulnerability Management

We actively monitor our application for potential vulnerabilities and encourage responsible disclosure.

  • Continuous Monitoring: We regularly scan our codebase and third-party dependencies for known security flaws.
  • Patching: Critical security updates are applied immediately, adhering to Atlassian’s Security Bug Fix Policy.

4. Incident Response and Contact

In the rare event of a security issue, we have a defined response plan to mitigate the impact.

  • Notification: We will notify affected users and Atlassian within 72 hours of confirming a security breach.
  • Reporting a Vulnerability: To report a security vulnerability or if you have questions about this policy, please contact us at jj1010uk@gmail.com.
